# Zametki
Zametki — a single‑file web app for visual note‑taking. Move cards, connect them with smooth Bezier lines, pick colors, switch themes. The board supports zoom and pan; all data is saved locally in the browser. No installation or internet needed. Perfect for brainstorming, planning, and mapping ideas.

How to run
1)Download zametki.html.
2)Open the file in any modern browser.
The application is entirely client‑side (HTML+CSS+JS), requires no installation, and works without an internet connection.
